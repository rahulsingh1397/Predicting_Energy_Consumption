# Predicting Energy Consumption
This project aims to predict energy consumption using household energy data. The dataset used for this project is the [London Homes Energy Data](https://www.kaggle.com/datasets/emmanuelfwerr/london-homes-energy-data).

## Dataset Description

The London Homes Energy Data dataset contains historical energy consumption data for households in London, UK. It includes the following features:

- **Date**: The date of the observation.
- **Energy Consumption (kWh)**: Daily total energy consumption.
- **Temperature (°C)**: Daily average temperature.
- **Humidity (%)**: Daily average humidity.
- **Wind Speed (km/h)**: Daily average wind speed.
- **Weather Description**: A textual description of the weather conditions.

This dataset provides valuable insights into household energy usage patterns, which can be analyzed to predict future energy consumption trends.

This project aims to predict energy consumption using weather data. The dataset used for this project is the [London Weather Data](https://www.kaggle.com/datasets/emmanuelfwerr/london-weather-data).

## Dataset Description

The London Weather Data dataset contains historical weather data for London, UK. It includes the following features:

- **Date**: The date of the observation.
- **Temperature (°C)**: Daily average temperature.
- **Dew Point (°C)**: Daily average dew point.
- **Humidity (%)**: Daily average humidity.
- **Wind Speed (km/h)**: Daily average wind speed.
- **Pressure (hPa)**: Daily average atmospheric pressure.
- **Precipitation (mm)**: Daily total precipitation.
- **Weather Description**: A textual description of the weather conditions.

This dataset provides a comprehensive view of London's weather, which can be used to analyze patterns and predict energy consumption trends.

## Project Goals

1. Preprocess and clean the dataset.
2. Perform exploratory data analysis (EDA) to identify trends and correlations.
3. Build predictive models to estimate energy consumption based on weather data.
4. Evaluate and optimize the models for better accuracy.

## Getting Started

1. Download the dataset from [Kaggle](https://www.kaggle.com/datasets/emmanuelfwerr/london-weather-data).
2. Place the dataset in the `data/` directory of this project.
3. Follow the instructions in the project notebooks to preprocess the data and build models.
